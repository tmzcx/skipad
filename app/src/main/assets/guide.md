# 跳过 · 使用指南（v1.0.0）

一句话：一个「看到开屏广告上的跳过/关闭按钮就帮你点一下」的无障碍工具，
外加一个百宝箱（连点器 / GitHub 加速 / 网站推荐 / 清理内存 / 图片解混淆 / 笔记 / 今日人品）。
不联网、不改别的应用、不需要 root。

## 一、第一次使用

1. 打开应用，点首页最上面的「去开启服务」，在系统设置里找到「跳过」并打开。
2. 回到应用，状态卡显示「服务运行中」就成功了。
3. 打开一个有开屏广告的应用试试，「跳过 3」「关闭广告」会被自动点掉。

无障碍被系统关掉后，按同样路径重新打开即可。小米 / Redmi 重启后一定会关无障碍，这是系统机制。

## 二、总开关

首页最上面的「总开关」是**一切功能的总闸**。关掉时会依次停掉：

- 开屏跳过（不再点击任何东西）
- 连点器（自动点击循环）
- DNS 通道 + GitHub 加速
- 笔记悬浮窗、灵动岛、连点控制板、点位标记

也就是关掉之后不会再有功能在后台跑。

## 三、三个名单

| 名单 | 作用 |
|---|---|
| 黑名单 | 完全不监控这个应用，不点、不看 |
| 跳转拦截 | 在这个应用里点完跳过，跳出到别的应用/落地页时立刻按返回 |
| 全程拦截 | 只要它在前台，就不限开屏那 12 秒，持续找广告关闭按钮 |

## 四、保活

- 应用信息 → 省电策略 → 无限制
- 应用信息 → 自启动 → 允许
- 最近任务里把「跳过」下拉锁定
- 首页「强制保活」打开后常驻通知 + 划掉后自启
- 「隐藏通知」：不显示横幅、不占锁屏，只静默运行

## 五、悬浮窗与灵动岛

小圆点可拖动、改大小/颜色/透明度，**支持 PNG 透明图和 GIF 动图**（API 28+ 原生播放）。

- 点一下：弹出灵动岛（打开 / 暂停拦截 / 清后台 / 笔记 / DNS 录入 / 关闭窗）
- 长按：关闭悬浮窗（可关掉这个行为）
- 「隐藏悬浮窗」：缩成 1 像素、全透明、点不到
- 「全屏游戏自动隐藏」：王者、原神等游戏在前台时自动藏起来
- 灵动岛里的功能项可以自由勾选（含「笔记」）

## 六、规则

- 内置规则约 20 条，覆盖通用「跳过 / 关闭广告」和常见广告 SDK
- 社区规则包来自 GKD 订阅，3029 条、覆盖 921 个应用，内置 40 条 GitHub 系域名映射
- 「严格匹配」默认开：只点「关闭 / 跳过 / 不感兴趣」这类按钮，宁可漏点不乱点
- 按分类开关：开屏广告 / 全屏广告 / 局部广告 / 内容更新 / 通知提示 …（「功能类」默认关）

## 七、百宝箱

1. **连点器**：取点准星选位置，设间隔和次数；支持多点同时点击、点位标记、悬浮控制板（吸附屏幕边缘）
2. **GitHub 加速**：DNS 直接返回优选 IP（内置 GitHub520 数据），不改证书、不做中间人
3. **网站推荐**：内置 29 个工具站，点一次随机抽一条，可复制链接
4. **清理内存**：快速清理走系统接口，深度清理走 Shizuku 的 `am kill-all`
5. **图片解混淆**：内置 PicEncrypt（MIT）6 种算法，支持混淆/解混淆、调节 key，一键自检还原
6. **笔记**：新建/编辑/删除、底色和文字色各 6 种、链接自动变蓝可点、粘贴剪贴板图片；
   悬浮窗可独立或整合进灵动岛，跨应用置顶显示
7. **今日人品**：按日期定值的抽签（同一天结果固定），带评语和假滚动动画

## 八、DNS 广告拦截（实验）

做法：开一个只接管 DNS 的本地 VPN，命中黑名单的域名直接返回「不存在」。

- 首次使用先授权 VPN（系统会弹「网络连接请求」）
- 黑白名单可手动输入，也能用灵动岛「DNS 录入」边看边录
- 「HTTPDNS 抑制」阻断应用内置 DNS，逼它走系统 DNS（副作用：部分应用启动卡几秒）
- 图片、视频、聊天、系统域名有保护名单，不会被误拦

限制：DoH（加密 DNS）或直连 IP 的应用拦不到。

## 九、常见问题

**Q：为什么有的广告跳过失败？**
开屏形式太多（纯图、视频、互动、摇一摇），工具只能点「有文字或 id 的按钮」。

**Q：熄屏重开会乱点吗？**
不会。熄屏会重置会话，只有真正出现新的启动页才开始工作；看图、相册、评论区、详情页一律不点。

**Q：会点到广告里吗？**
三层保护：只点按钮本身不点容器；点完 3 秒内跳到浏览器/商店会自动退回；一轮开屏只点一次。

**Q：要 root 吗？**
不需要。可选的 Shizuku 功能（禁广告组件、关链接跳转、深度清内存）也不需要 root。

## 十、隐私

- 默认不申请网络权限（DNS/GitHub 加速需要 VPN 权限但不读取内容）
- 所有规则、名单、笔记、日志都存在本机
- 不上传、不统计、不联网校验

## 十一、卸载前

先在「关于 → 恢复默认设置」清空配置，再关掉「强制保活」，最后卸载。
