# 跳过 · Skip

一个基于 Android 无障碍服务的开屏广告自动跳过工具，外加一个实用工具箱（百宝箱）。

> **重要提示：本项目作者不打算长期维护。** 代码按现状提供（AS IS），能跑通的功能见下方说明，
> 已知问题也一并列出，不保证修复。欢迎自行 fork 继续维护。

- 不 root、不收集数据、不修改任何第三方应用
- 只做一件事：**看到「跳过 / 关闭广告」这类按钮，帮你点一下**
- 所有配置保存在本机

---

## 适用系统

| 项 | 范围 |
|---|---|
| 最低版本 | **Android 8.0（API 26）** |
| 目标版本 | Android 16（API 36），compileSdk 36 |
| 实测机型 | Redmi 26020RN1AC（Android 16，720×1600） |
| 说明 | 悬浮窗 GIF 动图需要 **Android 9（API 28）** 及以上，低版本自动退化成静态首帧 |
| 说明 | 「深度清理内存」需要 [Shizuku](https://github.com/RikkaApps/Shizuku)；无 Shizuku 时不可用 |

未在 MIUI 之外的 ROM（ColorOS / OriginOS / 鸿蒙等）上系统性验证，个别机型的省电策略可能杀掉服务。

## 功能

### 广告跳过

- 识别开屏页里的「跳过 3」「关闭广告」等按钮并点击
- 三层保护：面积过大的节点不点、图片/评论/详情页不点、一轮开屏只点一次
- 黑名单（完全不监控）、跳转拦截（跳浏览器/商店自动返回）、全程拦截（不限开屏时段）
- 社区规则包（GKD 订阅转换，3029 条），支持严格匹配与分类开关

### 百宝箱

| 模块 | 说明 | 状态 |
|---|---|---|
| 连点器 | 取点准星、多点同时点击、点位标记、吸附边缘的控制板 | 可用 |
| GitHub 加速 | 内置 GitHub520 优选 IP，DNS 层直接回答，不做中间人 | 可用，未做长时间稳定性测试 |
| 网站推荐 | 常用工具站随机抽取 + 复制链接 | 可用 |
| 清理内存 | 快速清理（系统接口）/ 深度清理（需 Shizuku） | 无 Shizuku 时基本无效 |
| 图片解混淆 | 移植 PicEncrypt 的 6 种算法，支持混淆/解混淆与自检 | 可用 |
| 笔记 | 增删改、底色与文字色、链接可点、粘贴图片 | 编辑弹窗会被输入法遮挡 |
| 今日人品 | 按日期定值的日签 | 可用 |

### 其他

- DNS 广告拦截（实验）：本地 VPN 只接管 DNS，命中黑名单返回 NXDOMAIN
- 悬浮窗：自定义图片（支持 GIF）、隐藏模式、全屏游戏自动隐藏
- 总开关：一键停掉跳过、连点、DNS、笔记、全部悬浮面板

## 已知问题（未修复）

以下是**已知且尚未解决**的问题，使用前请先了解：

1. **滑屏时抢触控**
   列表/页面滑动过程中，悬浮窗或识别层可能抢走触摸事件，表现为滑动不跟手、滑到一半停住。

2. **误点 B 站图片**
   在 B 站看图时，图片查看器上的「关闭 / ✕」会被误判成开屏广告的关闭按钮，
   导致图片被意外关闭。同类图集类应用有相同风险。

3. **笔记编辑弹窗被输入法遮挡**
   全屏笔记页的「保存」按钮在键盘弹出时会被盖住，需要先收起键盘。

4. **笔记独立悬浮窗不稳定**
   笔气泡模式（`notesIndependent`）在服务重启后不一定恢复显示，
   该模式已基本弃用，建议改用「主悬浮窗 → 灵动岛 → 笔记」。

5. **快速清理内存无效**
   Android 8+ 普通应用枚举不到其它进程，没有 Shizuku 时会显示「已清理 0 个后台进程」。

6. **DNS 拦截对加密 DNS 无效**
   应用若使用 DoH / 直连 IP，绕过本地 DNS，拦截不生效。

7. **GitHub 加速的 IP 列表是快照**
   `github_hosts.txt` 为某一时刻的 GitHub520 数据，IP 可能过期，需自行更新。

## 因开源而调整的功能

为了让仓库可以安全公开，部分内容做了删改，功能上略有缺失：

- **网站推荐里移除了个别资源站链接**（版权风险），模块本身仍可用
- **不再内置 `shizuku.apk`**（第三方二进制不入库），
  「一键启动 Shizuku」需自行下载后放入 `app/src/main/assets/shizuku.apk`
- **签名密钥与本地路径已剔除**，自行编译需生成自己的 keystore
- 打包产物（APK）不随仓库发布

## 编译

需要 JDK 17+ 与 Android SDK（compileSdk 36）。

```bash
# 1. 在根目录创建 local.properties，指向你的 SDK
#    sdk.dir=/path/to/android-sdk

# 2. 生成自己的签名（可选，不签名也能编译 debug）
keytool -genkey -v -keystore app/skipad.jks -alias skipad \
  -keyalg RSA -keysize 2048 -validity 10000

# 3. keystore.properties（不要提交）
#    storeFile=app/skipad.jks
#    storePassword=***
#    keyAlias=skipad
#    keyPassword=***

./gradlew :app:assembleRelease
```
